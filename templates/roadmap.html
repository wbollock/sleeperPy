Planned Features

SleeperPy is free to use. This page tracks what is planned next and what is still exploratory.

Recently Shipped

  • Cross-league action feed on the dashboard: start/sit swaps aggregated across every league in one place, not buried per-league.
  • Advanced waiver wire recommendations with lineup context and suggested FAAB bids.
  • Trade retrospective: see how a trade played out days/weeks later.
  • League year badges to distinguish duplicate league names across seasons.

In Progress: Multi-Source Tiering

  • A second, genuinely independent weekly ranking source alongside Boris Chen (not another re-derivation of the same underlying expert consensus).
  • A second dynasty value source (FantasyCalc) to cross-check DynastyProcess on trade fairness and roster value.
  • Agreement/confidence indicator: when sources agree, high-confidence start/sit call; when they disagree, say so instead of false precision.
  • Cut Candidates: the "cut" side of add/cut/start/sit, currently the weakest-covered of the four.
  • Cross-league dedup so the same add/drop call isn't repeated once per league when it applies to several.

Eventual Ideas

  • League trend tracking across multiple seasons.
  • Expanded team need modeling for rookie drafts.
  • Waiver and trade actions in the cross-league dashboard feed (currently start/sit only).

How priorities are set

Priorities are based on bug impact first, then features that help lineup and roster decisions the most each week.

Feedback is welcome via GitHub issues.
